macOS 未签名安装说明

四步安全打开 e-Mate

请只使用官方下载页提供的安装包。
01

打开 DMG

在“下载”中双击 e-Mate 的 DMG 文件。

02

拖入应用程序

把 e-Mate 图标拖到“应用程序”文件夹，等待复制完成。

03

Control 点按

进入“应用程序”，按住 Control 键点按 e-Mate，然后选择“打开”。

04

确认仍要打开

在系统提示中选择“仍要打开”。以后可直接启动 e-Mate。

找不到“仍要打开”时

使用终端允许这一个 App

先核对下载页标注的 SHA-256

确认安装包摘要一致，并已将 e-Mate 拖入“应用程序”后，打开“终端”，运行这一条命令：

xattr -dr com.apple.quarantine "/Applications/e-Mate.app" && open -a "e-Mate"
