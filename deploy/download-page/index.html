e-Mate 2.0.7 · npm + 本地 Web

一条命令，
开始工作。

e-Mate 在你的电脑本地运行，通过浏览器使用。安装时只需要 Node.js 与 npm，不需要额外的桌面安装程序。

推荐 Node 24 LTS 支持 Node ^22.19 或 ≥24 版本 2.0.7

先安装 Node.js

如果终端中运行 node --version 和 npm --version 都能显示版本，可直接进入下一步。

获取 Node 24 LTS

首次安装

选择你的电脑

三个版本使用同一个已发布 npm 包，npm 会根据操作系统与架构安装正确内容。请在系统终端中逐行运行。

macOS · Apple Silicon

适用于 M1、M2、M3、M4 等 Apple 芯片。

npm install -g @e-mate/dsh@2.0.7
e-mate setup
e-mate launch

安装完成后

  1. 浏览器自动打开。本地服务不会因关闭网页而退出。
  2. 桌面出现 e‑Mate.command。setup 会覆盖式创建快捷方式，再次双击即可重开。
  3. 检查状态。运行 e-mate status；停止服务使用 e-mate stop。

覆盖更新

再次安装不会丢数据

先停止受管实例，再安装指定版本并重新执行设置。会话、附件、记忆、凭据引用与迁移收据保留在 e-Mate 数据目录中。

更新到 2.0.7

macOS 与 Windows 命令一致。

e-mate stop
npm install -g @e-mate/dsh@2.0.7
e-mate setup
e-mate launch

更新规则

同版本重装会校验环境、修复 profile，并覆盖 e-Mate 自己管理的桌面快捷方式。

未来更新时，将命令中的 2.0.7 换成下载页公布的新版本；有任务运行时，迁移会失败关闭。

e-Mate 是 npm 安装的本地 Web 应用，桌面快捷方式只是安全的启动入口。
