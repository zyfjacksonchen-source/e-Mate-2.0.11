在线更新

直接告诉 e-Mate 更新

应用内的 Agent 自然语言更新入口继续使用桌面端既有 updater，不需要手动安装 Node.js 或运行包管理命令。

自然语言更新

在 e-Mate 对话中发送“更新 e-Mate”或“检查并安装最新版本”，Agent 会进入现有桌面更新流程。

更新器与本页使用同一份正式桌面发布清单；清单或制品校验失败时不会降级到其他下载源。

需要手动重装时

从本页重新下载对应系统安装包并覆盖安装。不要在 e-Mate 正在执行任务时替换应用。

当前为未签名版本，覆盖安装时仍需遵循上方系统安全提示。
