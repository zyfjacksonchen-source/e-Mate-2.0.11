## Evidence rules

- This ticket runs only the manifest self-check. Existing product tests remain main-agent source-gate evidence.
- GUI receipts must record provenance, platform/build identity, result, external immutable URI, and SHA-256. Do not track screenshots, logs, prompts, images, installers, or secrets.
- Missing, mismatched, or unexecuted evidence remains **OPEN**; nearby tests, historical receipts, and another platform do not substitute.
- A `2.0.17-new` row becomes a regression claim only after implementation and its evidence pass.
