1. 读取唯一主 Goal；
2. 读取 `git status --short`、分支、HEAD、Base/Profile 与目标平台；
3. 完整读取 `AGENTS.md`、`target-contract.md`、本文件及最新一条 `development-log.md`；

## TTFT v2 证据合同摘要

- 每个样本记录：submit→首个可见文本 paint、`user/message`→首个非空 text delta、首个 chunk→paint、submit→Host、turn→request header、policy、quota、prepare、adapter→first chunk、provider invocation/response ID、usage、header SHA/bytes/tool count、stream throughput、Tool handoff、duplicate count 与独立 queue wait。
- 不记录提示/输出正文、密钥和敏感路径；跨进程时钟只做 correlation，不直接相减。
- 最终安装态 2.0.12↔2.0.13：每个正式聊天模型 30 组 AB/BA；每模型短文本、20-turn history、确定性只读 Tool 各 10 组。另做更新/重启后首请求 10 组、5000 events、长 Markdown/代码和 Goal active/inactive。
- 原生 DSH rc.7 Goal↔2.0.13 Goal：默认模型至少 30 组。不跨模型、冷热状态或场景平均。
- 门禁：TTFT p50 ≤基线 + `max(50ms, 3%)`；TTFT p95 ≤基线 + `max(100ms, 5%)`；本地 pre-provider p50/p95 ≤+10/+25ms；chunk→paint p95 ≤+10ms 且绝对≤50ms，p99≤100ms；throughput p50/p5 ≥97%/95%；Tool handoff p95 ≤+25ms 且≤+5%；duplicate=0；更新后冷启动首请求成对差≤500ms。消耗任一允许回退的 80% 时扩为 60 组。
- 普通聊天的系统头、工具头、路由、模型和推理档与 2.0.12 冻结基线字节级一致；只有原生 Goal 场景允许 rc.7 Goal 工具。Canvas、Preview、Pet 和其他 UI 不进入普通模型常驻工具头。

```markdown
## YYYY-MM-DD · 2.0.13 Sxx 标题

- Goal checkpoint:
- Frozen baseline / current HEAD:
- Binding documents read:
- Inspected native seam:
- Experiment or why unnecessary:
- Decision and forbidden alternatives:
- Changed scope:
- Verification commands and results:
- Immutable evidence / receipt:
- Remaining blockers:
- Next exact action:
```

日志 append-only；大型原始证据放既有 artifacts/receipts 路径，日志只写相对路径、SHA 和结论。切片没有终态日志视为未完成。新需求必须先记录 scope amendment，再改实现。子代理结果由主代理复核 diff 与测试后才能成为正式事实。
