## S04 性能

- 输入：5,000 事件固定会话、30 事件/秒流、20 会话开关场景、Chrome Trace 与 React Profiler。
- 修改边界：优先目标已有缓存/selector/virtualization；只有测量证明瓶颈后才改实现。
- 检查：冷启动、INP、事件到绘制、FPS、长任务、heap、泄漏和前后对比。
- 当前证据：固定会话 `e-mate-performance-5000-v1` 含 5,000 个目标持久事件、625 个 turn，事件 SHA-256 为 `ad12feaa53f9d55c22d0e32a366316c8e29a8031ccca5d27a8e4f97d2a99b0cc`。单一 Harness 实例通过目标 history paging 稳定加载 4,999 个聊天行后，实测约 45,300 个 DOM 节点、97–104 MB heap、58.4 fps、稳态无 >100 ms 长任务，满足当前发布预算；掉帧百分比按用户修订仅保留为诊断数据，不再作为发布门槛。行级 CSS containment 与 `content-visibility` 的不稳定实验均已撤回，没有为追逐非门槛指标修改 Harness ChatView。包内 Chromium 的 5 次全新浏览器上下文 LCP p75 为 400ms、可交互 p75 为 383.1ms；输入/侧栏/theme/Settings 的 INP p75 为 24ms，20 次企业策略模型切换的 60 个交互 p75 为 16ms、最大 96ms。20 会话堆增长重复为 9.53%/8.25%。真实目标事件流复测约 30.10 events/s、p95 43.30ms、p99 64.30ms、最大 97.80ms、无 >100ms 长任务。React 官方 DevTools hook 捕获一个 renderer、177 次 commit、每页 4 次 commit 和 0 error commit；production Profiler 摘要与最终发布候选重跑仍待补齐。完整结构结果见 `../../artifacts/performance/S04-2026-08-15-metrics.json`。
- 退出：满足 [`../performance-and-acceptance.md`](../performance-and-acceptance.md) 全部发布阻断预算。
- 依赖：S03。
