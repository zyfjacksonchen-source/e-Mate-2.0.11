## S04 性能

- 修改边界：优先目标已有缓存/selector/virtualization；只有测量证明瓶颈后才改实现。
- 检查：冷启动、INP、事件到绘制、FPS、长任务、heap、泄漏和前后对比。
- 当前证据：固定会话 `e-mate-performance-5000-v1` 含 5,000 个目标持久事件、625 个 turn，事件 SHA-256 为 `ad12feaa53f9d55c22d0e32a366316c8e29a8031ccca5d27a8e4f97d2a99b0cc`。单一 Harness 实例通过目标 history paging 稳定加载 4,999 个聊天行后，实测约 45,300 个 DOM 节点、97–104 MB heap、58.4 fps、稳态无 >100 ms 长任务，满足当前预算；掉帧百分比按用户修订仅保留为诊断数据，不再作为发布门槛。旧浏览器闭包曾测得 LCP/INP/事件延迟/heap 基线，但它已被删除，不能替代单一 tarball 在正式支持浏览器上的发布候选重跑。React production Profiler 摘要与最终候选重跑仍待补齐。完整历史结果见 `../../artifacts/performance/S04-2026-08-15-metrics.json`。
- 退出：满足 [`../performance-and-acceptance.md`](../performance-and-acceptance.md) 全部发布阻断预算。
