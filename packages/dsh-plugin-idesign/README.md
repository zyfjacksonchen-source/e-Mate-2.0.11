# e-Mate iDesign adapter

This component admits the verified MIT `deepseek-idesign@0.2.0` package into e-Mate's pinned DSH rc.7 profile. It keeps the native `conversation.view` and workspace registry paths, stages “让小芯协助” text into the current draft without submitting, and stores design files only under the active workspace's `design/` directory.

The catalog is intentionally limited to five locally self-contained Apache-2.0 templates. Templates requiring runtime CDNs or Google Fonts, templates without adequate bundled license evidence, and the proprietary WeChat template are not shipped.
