# @e-mate/dsh-plugin-subagent

This is an e-Mate clean-room compatibility receipt, not a fork of `dsh-plugin-yet-another-subagent`. The requested behavior already exists in the pinned upstream `0.1.0-rc.7` standard preset: host-owned subagent registry and spawn/fork providers, agent-plane delegation and control Tools, continuable child reports, durable child sessions, real Tool/session events, and native Job settlement.

Its Cordis patch is intentionally empty. e-Mate must keep the target standard preset rows instead of registering duplicate providers, Tools, transports, stores, or routers. The exported descriptor gives setup and release checks one exact compatibility receipt.
