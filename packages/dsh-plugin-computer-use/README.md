# @e-mate/dsh-plugin-computer-use

Computer Use is exposed only when the current user request explicitly inserts `@电脑操控`. The visible user message keeps that exact label instead of an internal activation marker. The model cannot enable it on its own, and a grant from a prior turn is not reused. Webpage work uses the CDP browser adapter first.

This package embeds the exact MIT-licensed `Anionex/dsh-computer-use` commit recorded in `SOURCE.md` and adapts its bundle identity to e-Mate 2.0.17 on Harness rc.7. Its Windows backend incorporates only the audited MIT Win32 primitives and exact blobs recorded there. Both platforms stay on the same native DSH Tool, Skill, Settings, approval, storage, attachment, subprocess, Service, and Profile owners.

Darwin retains the pinned Accessibility/CoreGraphics provider unchanged. Win32 selects one UI Automation backend. The shipped Profile preserves foreground focus for pointer and keyboard actions on both platforms; pointer routing remains targeted, with the platform cursor policy unchanged. macOS uses Accessibility or pid-targeted keyboard delivery without activation. Windows UI Automation value changes can work in the background, but raw keyboard fallback requires the target already be foreground and fails closed rather than activating it. Public application values contain only an opaque path hash, PID, and name; executable path, process start time, and HWND remain private object-identity sidecars used for fresh state-hash checks. Windows cursor visualization is hidden because no native exact-target overlay exists. Capture uses only the validated window and workspace-fenced host path; UIA patterns are preferred, while fallback uses checked target-window messages after foreground verification. Health grants UIA and capture only after direct probes. Secure desktop, elevated/UIPI targets, locked or noninteractive sessions, unsupported RDP transitions, stale targets, integrity failures, and unavailable authority fail closed. This is source/component support only; no Windows build, installation, or installed-machine success is claimed.
