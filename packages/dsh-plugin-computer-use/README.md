# @e-mate/dsh-plugin-computer-use

This package embeds the exact MIT-licensed `Anionex/dsh-computer-use` commit recorded in `SOURCE.md` and adapts its bundle identity to e-Mate 2.0.11 on Harness rc.7. It stays on the native DSH Tool, Skill, Settings, approval, storage, attachment, and subprocess seams.

The native provider is enabled only on macOS 14 or newer. Windows remains supported by e-Mate, but this macOS Accessibility provider is disabled there rather than replaced with an unverified automation path.
