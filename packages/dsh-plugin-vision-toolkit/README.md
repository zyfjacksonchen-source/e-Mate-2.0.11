# @e-mate/dsh-plugin-vision-toolkit

This package is the e-Mate `2.0.11` Profile component for `Anionex/dsh-vision-toolkit` commit `29850a83871d4b7a7cc13e251420c5a440e2f69e`.

It keeps the upstream DSH Tool, Skill, Subprocess, Settings, Agent and session lifecycle. The adapter supplies the architecture-matched Python runtime through the fixed Desktop Base ABI and projects only the image-capable enterprise model route into the upstream Settings namespace.

The copied upstream Settings registration has one bounded compatibility hook: every resolved configuration must exactly match the current enterprise projection. Manual Settings edits, alternate credentials, alternate endpoints and alternate models fail closed. The upstream client is shipped for pasted images, Tool views, artifact preview/download and health, while managed provider/runtime controls are read-only.

Each target-specific component artifact contains the upstream Python scripts and the complete signed offline wheel closure for that platform. The immutable Base contains only the fixed CPython carrier; changing Vision/OCR code or Python dependencies therefore uses the component release lane without rebuilding the Desktop installer.
